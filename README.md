# Planta do Projeto 3D

Visualização do terreno em 3D, 2D (4 estilos de planta) e Street View.

## Publicar no Vercel
1. Suba estes arquivos para um repositório no GitHub.
2. No Vercel: Add New > Project, escolha o repositório e publique com as opções padrão (sem build).

Precisa de internet para carregar o motor 3D (jsDelivr) e as fontes (Google Fonts).
